# KDP trim and bleed checklist (Princess Baylin picture books, ~24-32 pages)

Pulled from official Amazon KDP Help pages, 2026-10-01. Previously blocked for four days (28 Sep to 30 Sep) by no web access in the headless session; web tools worked this run.

## Recommended trim size

KDP's own help pages do not single out one size as "the" picture-book size; they list the general paperback trim catalogue. For a 24-32 page picture book, the common square-ish or landscape-leaning choices from that catalogue are:
- 8.25" x 11" (large trim, closest to a classic picture-book feel)
- 6" x 9" (KDP's default trim, more compact)
- 7" x 10" (middle ground)

Full catalogue (inches): 5x8, 6x9 (default), 6.14x9.21, 7x10, 8.25x11. Custom sizes are allowed: width 4"-8.5", height 6"-11.69".

## Bleed

- Full-bleed interior art: extend 0.125" (3.2 mm) beyond the final trim size on top, bottom, and outer edges.
- Covers: 0.125" (3.2 mm) bleed required on all sides.

## Safe margin

- Keep any content you don't want trimmed at least 0.25" (6.4 mm) from the outside cover edge.

## Interior margins (24-150 page band, which covers a 24-32 page book)

- Inside/gutter margin: 0.375" (9.6 mm)
- Outside margin, no bleed: at least 0.25" (6.4 mm)
- Outside margin, with bleed: at least 0.375" (9.6 mm)

## PDF page size formula (full-bleed interior)

Format the interior PDF 0.25" (6.4 mm) taller and 0.125" (3.2 mm) wider than the selected trim size.
Example: a 6" x 9" book needs a bleed PDF page of 6.125" x 9.25".
